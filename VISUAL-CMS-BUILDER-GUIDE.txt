LIVE PREVIEW
The Pages collection now has a structured visual preview that shows section order,
labels, headings, text, representative cards and stats while editing.

IMPORTANT
Decap is a structured visual block editor, not Webflow.
It supports drag-reorder, add and delete sections, but it does not provide reliable freeform
mouse resize handles or arbitrary drag-anywhere positioning.

DUPLICATION
Decap's typed list blocks do not provide a dependable native one-click Duplicate action.
Use Add Section and choose the same block type. This package avoids brittle DOM-based duplication
because it can corrupt content.

DEPLOYMENT
Replace the existing repository files with everything inside this package.
